# VYTRIX Test Sample Data

**Specification:** `SPEC.md` Section 13 (Round 1 Submission Deliverable: *Code repository with setup instructions and sample data in a test directory*).

---

## Required Files for Competition Submission

To satisfy the Round 1 brief with genuine physical data, the user must populate this directory with real artifacts from their physical home reconstruction:

### 1. `test/data/capture_meta.json` (Required)
Metadata describing your actual recording session:
- `dataset_status`: Set to `"real_home_capture"`
- `device`: Smartphone model (e.g. `"iPhone 14 Pro"`, `"Samsung Galaxy S23"`)
- `resolution`: e.g. `[3840, 2160]` or `[1920, 1080]`
- `fps`: e.g. `30`
- `scale_reference`: Real measured distance (e.g. `1.00` m floor tape)
- `room`: Description of physical space captured

### 2. `test/data/frames/` (Required: ~10 to 15 frames)
Extract 10–15 sample `.jpg` frames from your video (or copy them from `data/work/preprocess/frames/`) into `test/data/frames/`.
- Must show the floor tape marker and multiple viewpoints of the room.
- Verify image files are non-empty and readable.

*Alternative:* A short 5–10 second sample video clip saved as `test/data/sample_clip.mp4` (< 20 MB).

### 3. `test/data/scene.splat` (Required)
The trained 32-byte `.splat` file generated by the pipeline (`data/work/optimize/scene.splat`).
- Must be under GitHub's 100 MB file limit (optimally 15–40 MB).
- Validated by `test/test_sample_data.py`.
